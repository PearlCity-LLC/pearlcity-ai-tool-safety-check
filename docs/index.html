Is this AI-built tool safe to install?

Paste a GitHub repo. You get a plain-English red / amber / green card: is it still maintained, and does it pass basic security checks? Everything runs in your browser using the public GitHub API and the OpenSSF Scorecard. Nothing is stored.

Try: ossf/scorecard · ggml-org/llama.cpp

What it checks

  • Maintained: last push, weeks with commits in the last 90 days, number of contributors, closed issues, releases.
  • Trust: license, stars/forks (weak signal), repo age, archived or fork.
  • Security: OpenSSF Scorecard overall score, dangerous CI workflows, known vulnerabilities, checked-in binaries.

A green card is not a guarantee, and a red card isn't proof of malice. It's a 10-second first look so you know when to dig deeper.

A free tool by Pearlcity LLC. Not affiliated with GitHub or OpenSSF. GitHub allows about 10 checks per hour per network without a login.
